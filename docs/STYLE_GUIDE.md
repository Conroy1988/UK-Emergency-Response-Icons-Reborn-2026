# Icon system

- Canvas: 32 × 37 pixels, transparent RGBA.
- Body: dark high-contrast map pin with a service-coloured side rail.
- Pictogram: one of the deterministic incident families defined by the title,
  MissionChief category and required capabilities.
- Badge: permanent 1–5 TKB Response Level in the upper-right corner.
- Status: MissionChief selects the red, amber or green version automatically.
- Outline: dual light/dark edge survives light, dark, satellite and greyscale
  map backgrounds.
- Source: all pixels are generated from code; no external logos, fonts,
  registrations or copied artwork are embedded.

The three status colours mean:

- Red: new mission or action still required.
- Amber: response under way.
- Green: required resources covered/on scene.
